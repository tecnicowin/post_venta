CÓMO TOMAR LAS CAPTURAS
================================================================================

WINDOWS:
  - Presiona Win + Shift + S (recorte selectivo)
  - O presiona Win + PrtSc (pantalla completa)

NOMENCLATURA:
  - Usa el nombre exacto indicado arriba
  - Formato PNG
  - Mayúsculas y guiones como se indica

EJEMPLO:
  01-login.png
  03-dashboard.png
  16-factura-productos.png

================================================================================
NOTAS PARA CADA SECCIÓN
================================================================================

1. LOGIN (01-login.png)
   - Mostrar la pantalla de PIN
   - NO mostrar el PIN digitado

2. CAMBIO DE PIN (02-cambio-pin.png)
   - Capturar el modal de advertencia
   - Mostrar que pide PIN actual y nuevo

3. DASHBOARD (03-dashboard.png)
   - Mostrar stats (ventas, facturas, productos, stock bajo)
   - Que se vea el banner de demo si aplica

4. CONFIGURACIÓN (05-configuracion.png)
   - Capturar toda la página scrolleando
   - O hacer 3 capturas: datos, IVA, impresora

5. FACTURACIÓN (15-17)
   - Capturar editor vacío
   - Luego con productos agregados
   - Mostrar columna de margen visible

6. PAGO (20-pago-modal.png)
   - Mostrar las 7 formas de pago

7. LICENCIA (35-37)
   - Demo: mostrar banner
   - Activar: modal con campo de clave
   - Activa: mostrar nombre de empresa
